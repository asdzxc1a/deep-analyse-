# Scripted Shooting Boards Design

## Goal

Turn the cold-audience concept layer for the fashion creator account into a production-ready execution artifact.

The existing strategy pack already defines:
- creator doctrine
- content pillars
- platform roles
- first 2-week plan
- cold-audience concept directions

What is still missing is the exact layer between concept and shoot execution:
- exact opening line
- exact first 3 seconds
- exact shot order
- exact edit rhythm
- exact caption direction
- exact cover text
- exact platform-specific variation

This slice fills that gap.

## Problem

The earlier production board is structurally useful, but it is too safe and too obvious for the current growth goal.

The target account needs cold-audience content that feels:
- interruptive
- emotionally tense
- visually surprising
- character-driven
- resolved through a luxury payoff

That means the working production document cannot stop at high-level concepts. It must specify how each post earns retention in the first seconds and how the reveal is delayed, framed, and released.

## Scope

This slice should produce three connected artifacts:

1. A refined production board for the first 2 weeks
- schedule-level overview
- batch planning
- board-to-post mapping

2. A cold-audience concept board
- retained as the idea bank and selection layer

3. A new scripted shooting board file
- five priority concepts
- fully scripted for production use

## Creative Standard

Each scripted board must preserve the approved creative model:

1. interrupt
2. tension
3. character
4. luxury payoff

Each selected concept should feel less like a normal fashion transformation and more like a micro-story built for cold audiences.

The boards must avoid:
- generic before-and-after pacing
- soft or decorative openings
- overexplained captions
- safe “pretty content” logic

## Selected Concept Types

The first scripted boards should cover the strongest mix of use cases:
- fast refusal-based tension
- impossible transformation tension
- anti-reaction reveal
- luxury-location power dynamic
- editorial ending after chaos

This gives the pack a balanced first set for TikTok, Instagram, and YouTube Short adaptation.

## File Responsibilities

### `marketing-superpowers/strategy/account/production-board-weeks-1-2.md`

Purpose:
- map the 2-week schedule to specific scripted boards
- show batch logic and posting order

### `marketing-superpowers/strategy/account/cold-audience-concept-board-v1.md`

Purpose:
- remain the concept selection bank
- continue to explain the attention model and idea screen

### `marketing-superpowers/strategy/account/scripted-shooting-boards-top-5.md`

Purpose:
- become the actual working production document
- let a team shoot and edit without guessing the structure

## Validation

The strategy-pack validation script should treat the scripted shooting boards as a required artifact.

It should verify:
- the concept board exists
- the production board exists
- the scripted board file exists
- the scripted board file contains exact execution sections such as:
  - opening line
  - first 3 seconds
  - shot list
  - edit rhythm
  - platform variation

## Success Criteria

This slice is successful when:
- the strategy pack contains a real production-grade execution file
- the strongest five concepts are shootable without further idea work
- the 2-week board points to those scripts clearly
- the validation script enforces the new execution layer
