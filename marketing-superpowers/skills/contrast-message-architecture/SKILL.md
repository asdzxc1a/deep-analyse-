# Contrast Message Architecture

Define the creator's message architecture before scaling content.

## Purpose

Make sure every post fits:
- the tomboy/high-fashion contrast
- the creator's emotional promise
- the same recognizable content world

## Define

1. Creator identity
- wild
- funny
- impossible to ignore

2. Content world
- fashion as transformation
- personality as amplification
- chaos plus payoff

3. Emotional promise
- surprise
- fun
- confidence

4. Boundaries
- what fits the brand
- what breaks the brand
- what becomes too polished or too generic

## Output

Always produce:
- creator identity statement
- emotional promise
- content pillar definitions
- red flags for off-brand ideas
