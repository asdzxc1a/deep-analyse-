# Creator Content Planning

Turn strategy into a weekly content system instead of random posting.

## Purpose

Produce:
- weekly content buckets
- platform roles
- recurring series
- a test matrix for hook and format experiments

## Required Outputs

1. Weekly content system
- number of posts
- platform split
- production cadence

2. Content buckets
- contrast transformations
- attitude moments
- character series
- behind-the-look stories

3. Platform roles
- TikTok as virality engine
- Instagram as identity engine
- YouTube as attachment engine

4. Test matrix
- hook variations
- reveal timing
- personality-first versus transformation-first openings

## Guardrail

Every weekly plan must preserve the contrast identity and should not drift into generic fashion content.
