# Posting Readiness Check

Verify that a post is actually ready to publish.

## Verify

Check:
- platform fit
- pacing
- reveal strength
- cover strength
- caption alignment
- CTA discipline
- publish readiness

## Output

Always produce:
- readiness decision
- blocking issues
- final publish notes
- platform-specific risks

## Platform Routing

Use the relevant reviewer prompt for:
- Instagram via `prompts/instagram-reviewer-prompt.md`
- TikTok via `prompts/tiktok-reviewer-prompt.md`
- YouTube via `prompts/youtube-reviewer-prompt.md`
