# Marketing Superpowers

`marketing-superpowers` is a marketing operating system built from the strongest workflow ideas in `superpowers`, then specialized into vertical systems.

The first vertical is a fashion creator growth system for an eight-year-old creator whose edge is the contrast between:
- wild tomboy energy
- funny, chaotic personality
- high-fashion visual transformation

## What This Vertical Optimizes For

This system is built for:
- audience growth
- repeatable virality
- stronger recognizability
- creator authority over time

It is not built first for:
- premium brand positioning
- sponsorship optimization
- product sales funnels

## Core Operating System

The creator system keeps the same six-stage operating structure:
- diagnosis
- planning
- messaging
- review
- launch verification
- postmortem

## Platform Roles

- TikTok: virality engine
- Instagram: identity engine
- YouTube: attachment and authority engine

## Vertical Skills

- `creator-diagnosis`
- `creator-content-planning`
- `contrast-message-architecture`
- `viral-content-review`
- `posting-readiness-check`
- `content-postmortem`

## Operating Discipline

This repo preserves the strongest structural rules from `superpowers`:
- approval gates before major direction changes
- iterative review loops before publishing
- verification before claiming readiness
- escalation when age, safety, identity, or strategic clarity are at risk

## Content Strategy Shape

The vertical system is built around four content buckets:
- contrast transformations
- attitude moments
- character series
- behind-the-look stories

Use this repo to turn creator growth into a repeatable system, not a random posting habit.
